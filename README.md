# ⚡ Calculadora de desconto progressivo

Projeto desenvolvido em Python para calcular os descontos aplicados progressivamente 5, 10 e 15%.

## 🚀 Tecnologias Utilizadas

![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white)
![GitHub](https://img.shields.io/badge/GitHub-181717?style=for-the-badge&logo=github&logoColor=white)
![VS Code](https://img.shields.io/badge/VS_Code-007ACC?style=for-the-badge&logo=visualstudiocode&logoColor=white)

## 🔋 Funcionalidades

- Calcular o desconto aplicado nas compras
- Entrada do valor da compra
- Interface simples no terminal

## 💡 Exemplo

Compra valor: R$ 150
Desconto aplicado: 5%
Valor final a pagar: R$ 142.50
